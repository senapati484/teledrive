# Security Policy

## Supported Versions

Security updates and patches are actively maintained for the following versions of TeleDrive:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The TeleDrive team takes security and privacy very seriously. We appreciate the responsible disclosure of security vulnerabilities by security researchers and the open-source community.

### How to Report

If you discover a security vulnerability in TeleDrive:

1. **Do not create a public issue.** Please do not report security-sensitive issues or vulnerabilities through public GitHub issues or public chat.
2. **Submit via GitHub Private Vulnerability Reporting:**
   - Go to the [Security Advisories](https://github.com/senapati484/teledrive/security/advisories) tab of this repository.
   - Click **"Report a vulnerability"** to open a private advisory draft.
3. **Alternative Contact:**
   - If you cannot use GitHub Security Advisories, send an email to [sayansenapati@gmail.com](mailto:sayansenapati@gmail.com) with the subject `[TeleDrive Security Vulnerability]`.

### What to Include

Please provide as much information as possible to help us reproduce and fix the issue promptly:

- Type of vulnerability (e.g., token leakage, path traversal, injection, cryptographic flaw, memory safety)
- Full step-by-step instructions to reproduce the issue
- Proof of Concept (PoC) code, scripts, or network request samples (if applicable)
- Affected platforms or configurations (macOS, Windows, Linux, Android, iOS)
- Any proposed remediation or patches

### Response Process

1. **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **48 hours**.
2. **Investigation:** We will investigate and confirm the report, keeping you informed of our progress.
3. **Patch & Release:** Once resolved, a patched release will be prepared and published.
4. **Credit:** With your permission, we will credit your responsible disclosure in the release notes and advisory.
