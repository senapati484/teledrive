TeleDrive for macOS (Universal: Apple Silicon M-Series + Intel x86_64)
Version 0.1.4
================================================================================

HOW TO INSTALL:

METHOD 1 (RECOMMENDED - 1-CLICK INSTALLER):
  Double-click "Install TeleDrive.command".
  This automatically copies TeleDrive to /Applications, configures macOS
  security permissions, and launches the app directly with no warning dialogs.

METHOD 2 (DRAG & DROP):
  1. Drag "TeleDrive.app" into the "Applications" folder.
  2. Open TeleDrive from /Applications.
  3. If macOS displays "cannot be opened because the developer cannot be verified"
     or "Apple cannot check it for malicious software":
       - Go to Apple Menu  -> System Settings -> Privacy & Security
       - Scroll down to "Security"
       - Click "Open Anyway"
     (Or run in Terminal: xattr -cr /Applications/TeleDrive.app)

Why does macOS show this notification?
Apple requires developers to pay an annual $99 subscription fee for automatic
cloud verification. Because TeleDrive is 100% free, community-driven open-source
software, we do not lock distribution behind paid Apple developer accounts.
Your data, Telegram session, and credentials remain 100% on your device.

Enjoy using TeleDrive!
