## 💡 为什么选择 TeleDrive？

Telegram 在私有频道中提供了近乎无限的云端存储容量，但缺乏文件夹层级、虚拟目录索引以及传统桌面云盘的操作体验。**TeleDrive** 完美填补了这一空白：

- **无中间中继服务器**：所有文件上传下载及 MTProto 网络协议通信均由本地设备直连 Telegram 官方数据中心。
- **虚拟云盘工作流**：多层级文件夹、即时搜索、加星标、归档与回收站均由置顶在频道内的 gzip 压缩 Schema v3 目录索引统一管理，并由本地 IndexedDB 进行高速缓存。
- **客户端隐私与加密保险箱**：本地登录凭证保存在原子的 Rust 键值保险箱 / Tauri Stronghold 快照中，上传文件支持可选的零知识 `TDE1` PBKDF2-SHA256 + AES-256-GCM 端到端加密。
- **多账号无缝切换**：支持在多个手机号之间一键切换，会话与本地加密存储完全独立隔离。

## ✨ 核心特性

- **硬件生物识别与应用锁 (v0.1.5)**：通过 Touch ID、Windows Hello 和 Android 生物识别保护网盘，支持 4–6 位动态安全 PIN 码、系统多任务切换防窥隐私遮罩以及超时自动锁屏计时器。
- **应用内在线更新检查 (v0.1.5)**：基于官方发布的自动后台与即时语义版本检查，具备应用内更新弹窗提醒与直达 SourceForge 安装包下载能力。
- **真·无限制云存储**：以私人 Telegram 频道作为永久后端，无任何持续订阅费用；具备 SHA-256 重复文件秒传识别（`<= 2 GiB` 零上传秒级消息克隆）与断点续传检查点机制。
- **突破单文件体积上限 (`> 2/4 GB`)**：自动将超大文件切分为确定性顺序分段，在下载时无缝流式拼接还原。
- **可选端到端零知识加密 (`TDE1`)**：基于客户端 PBKDF2-SHA256 + 512 KiB 分块 AES-256-GCM 高性能加密，支持随机访问分块 Seek。
- **万能内置预览器与网格缩略图**：
  - 图片、浏览器可播放视频、PDF 文件（首页）的原生网格缩略图渲染。
  - 原生支持 PDF 预览 (`pdf.js`)、微软 Office 与 OpenDocument 文档 (`.docx`, `.odt`, `.rtf`, `.epub`)、多工作表表格 (`.xlsx`, `.ods`, `.csv`, `.tsv`)、演示幻灯片 (`.pptx`, `.odp`)、交互式压缩包 (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`)、沙箱隔离 HTML、CodeMirror 6 代码编辑（支持 50+ 种语言）、UTF-16 文本、HEIC 图片以及全格式媒体流播放。
- **极简原生跨平台**：基于 Tauri v2 与 Rust 构建，轻量高效，内存占用极低（通常低于 250 MB）。
- **自动化文件夹备份与跨设备同步**：带有本地事务日志的 `v2` 增量备份引擎与多端实时 Delta 差异拉取轮询机制。
- **原生支持 11 种国际化语言**：简体中文、繁体中文、英语、西班牙语、德语、法语、葡萄牙语、俄语、印地语、印度尼西亚语与日语。
- **流水线化 MTProto 引擎**：512 KiB 分块直传，支持多达 3 个并发 MTProto `upload.GetFile` / `SaveBigFilePart` 传输工作线程与自适应 `FloodWait` 限速流控。

## ⚙️ 架构原理

```
┌─────────────────────────────────────────────────────────────────┐
│                       React 19 前端展示层                       │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Zustand 全局状态 │             │ GramJS 客户端核心   │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           直连 MTProto
         (内部桥接调用)                        (安全 SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Tauri Rust 核心     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │      (私有专属频道)     │
│  │ Stronghold 保险箱 │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **直接通讯连接**：通过安全的 TLS 443 端口直连 Telegram 官方 MTProto 节点并完成鉴权。
2. **流水线分块传输**：大文件自动切分成 512 KiB 块并发传输，带断点续传检查点，超 2/4 GiB 文件自动多段分片。
3. **置顶目录索引与本地缓存**：通过单写入队列 `IndexQueue` 维护置顶于频道的 gzip 压缩 Schema v3 目录树，并在启动时从本地 IndexedDB (`teledrive_cache_v1`) 秒级恢复。

> 📘 **深度技术指南：** 查阅系统边界、时序图、Tauri Rust IPC 命令、加密格式与底层模块拆解，请参阅 [**技术架构设计与工程指南 (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md)。

## 🚀 快速上手

### 🛠️ 开发者与贡献者极速起步

TeleDrive 100% 源代码开源，且内置开发环境免配置凭据，无需单独去 Telegram 注册开发者 App，2 分钟内即可在本地启动运行。

#### 1. 克隆代码仓库
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. 安装项目依赖
```bash
npm install
```
> ℹ️ *`postinstall` 钩子会自动对 GramJS 注入 Tauri 和浏览器环境兼容补丁 (`scripts/patch-telegram.cjs`)。*

#### 3. 启动开发服务器
```bash
# 启动跨平台桌面应用（支持 Tauri v2 热重载）：
npm run tauri dev

# 或在浏览器中预览 Web 客户端：
npm run dev
```

### 📋 环境要求

在本地构建或运行之前，请确认您的系统满足以下最低配置要求：

| 配置项 | 最低版本要求 | 说明 |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (推荐 `v20+` LTS) | JavaScript/TypeScript 运行时及包管理器 |
| **Rust** | 最新稳定版 (`rustup default stable`) | 编译 Tauri 本地 Rust 核心必需 |
| **系统编译工具链** | 依据操作系统而定 (见下方) | C/C++ 编译器及 WebView 底层支持库 |

#### 各平台编译依赖
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（勾选“使用 C++ 的桌面开发”）。
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)（Windows 10/11 通常已自带）。

### 🔑 Telegram API 凭据配置（可选）

TeleDrive 已内置本地开发凭据。如需接入您个人的 Telegram 应用：
1. 使用手机号登录 [**my.telegram.org**](https://my.telegram.org)。
2. 进入 **API development tools** 创建应用（例如 `TeleDrive-Dev`）。
3. 复制生成的 `api_id` 与 `api_hash`。
4. 在软件内的 **设置 → API 配置** 中填入，或在项目根目录新建 `.env` 文件：
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
