## 💡 なぜ TeleDrive なのか？

Telegram はプライベートチャンネルで実質無制限のクラウド容量を提供しますが、フォルダー階層や仮想カタログ、デスクトップドライブ風の操作体系が備わっていません。**TeleDrive** はその課題を解決します：

- **中継サーバー完全排除**：すべてのファイル操作と MTProto 通信は、ローカル環境から直接 Telegram データセンター間で行われます。
- **仮想ドライブ設計**：階層フォルダー、高速検索、お気に入り、アーカイブ、ゴミ箱は、チャンネルにピン留めされた gzip 圧縮 Schema v3 カタログで管理され、ローカル IndexedDB にキャッシュされます。
- **クライアントサイド秘匿性＆安全な保管庫**：ログイン認証情報はアトミックな Rust キーバリューストア / Tauri Stronghold スナップショットに保持され、アップロードファイルは任意のゼロ知識 `TDE1` PBKDF2-SHA256 + AES-256-GCM で保護されます。
- **マルチアカウント対応**：セッションとローカル保管庫を完全分離した状態で、複数の電話番号アカウントをワンクリックで切り替え可能です。

## ✨ 主な機能

- **ハードウェア生体認証＆アプリロック (v0.1.5)**：Touch ID、Windows Hello、Android 生体認証による安全なロック解除、4〜6桁のカスタマイズ可能な動的PIN、OSアプリスイッチャー用のプライバシー保護シールド、無操作自動ロックタイマーを搭載。
- **アプリ内リアルタイムアップデート確認 (v0.1.5)**：バックグラウンドおよび手動でのセマンティックバージョン自動確認、アプリ内アップデート通知、SourceForge からの直接インストーラーダウンロードに対応。
- **真の無制限クラウド**：非公開 Telegram チャンネルをバックエンドストレージとして活用し、月額費用は永年ゼロ。SHA-256 重複検出（`<= 2 GiB` ゼロアップロード即時複製）と再開可能なアップロードチェックポイント。
- **単一ファイル制限の回避 (`> 2/4 GB`)**：巨大ファイルを決定論的順序で自動分割し、ダウンロード時にストリーミングで結合再生。
- **任意のゼロ知識 E2EE (`TDE1`)**：クライアント側 PBKDF2-SHA256 + 512 KiB 分割 AES-256-GCM によるランダムアクセス対応ブロック暗号化。
- **ユニバーサル内蔵プレビュー＆グリッドサムネイル**：
  - 画像、ブラウザ再生可能な動画、PDF（1ページ目）のグリッドサムネイル。
  - PDF (`pdf.js`)、Office および OpenDocument ファイル（`.docx`, `.odt`, `.rtf`, `.epub`）、複数シート表計算（`.xlsx`, `.ods`, `.csv`, `.tsv`）、プレゼンテーション（`.pptx`, `.odp`）、対話型アーカイブ（`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`）、分離 HTML、CodeMirror 6 コードエディター（50以上の言語対応）、UTF-16 テキスト、HEIC 画像、各種メディアストリーミング。
- **超軽量ネイティブクロスプラットフォーム**：Tauri v2 + Rust を採用し、メモリ消費量は通常 250MB 未満と極めて軽量。
- **自動フォルダーバックアップ＆マルチデバイス同期**：耐障害性に優れたジャーナル式 `v2` ローカルマニフェストと、複数端末間での差分同期ポーリング。
- **11言語のネイティブ多言語対応**：日本語、英語、スペイン語、ドイツ語、フランス語、ポルトガル語、ロシア語、中国語（簡体字・繁体字）、ヒンディー語、インドネシア語を完全サポート。
- **パイプライン化 MTProto エンジン**：最大 3 並列の MTProto `upload.GetFile` / `SaveBigFilePart` ワーカーと適応型 `FloodWait` レートリミット制御。

## ⚙️ システム構成と仕組み

```
┌─────────────────────────────────────────────────────────────────┐
│                       React 19 フロントエンド                    │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Zustand State    │             │ GramJS クライアント │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           直接 MTProto
       (Bridge 呼び出し)                      (セキュア SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Tauri Rust Core     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │    （非公開チャンネル） │
│  │ Stronghold 保管庫 │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **直接接続**：TLS ポート 443 経由で Telegram の MTProto サーバーへ直接安全に認証接続します。
2. **パイプライン転送**：ファイルを 512 KiB ごとのチャンクに分割し、チェックポイント、任意 `TDE1` AEAD 暗号化、2/4 GiB 超過ファイルのマルチセグメント処理を行います。
3. **ピン留めカタログ索引＆ローカルキャッシュ**：単一ライター `IndexQueue` によりチャンネルへ gzip 圧縮 Schema v3 JSON カタログを常時同期し、IndexedDB (`teledrive_cache_v1`) から高速復元します。

> 📘 **詳細な技術仕様：** システム境界、シーケンス図、Tauri Rust IPC コマンド、暗号化仕様などは、[**技術アーキテクチャ設計書 (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md) をご覧ください。

## 🚀 はじめに

### 🛠️ 開発者・コントリビューター向けクイックスタート

TeleDrive は完全オープンソースであり、開発用ダミー認証情報が内蔵されているため、Telegram 開発者ポータルでアプリを作成することなく 2 分以内に開発を開始できます。

#### 1. リポジトリをクローン
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. 依存関係のインストール
```bash
npm install
```
> ℹ️ *`postinstall` フックにより、Tauri およびブラウザ環境に必要な GramJS MTProto 互換パッチ (`scripts/patch-telegram.cjs`) が自動適用されます。*

#### 3. 開発サーバーの起動
```bash
# Tauri v2 のホットリロード付きクロスプラットフォームデスクトップアプリを起動：
npm run tauri dev

# またはブラウザで Web クライアントプレビューを起動：
npm run dev
```

### 📋 開発要件

ローカルでビルド・実行する前に、環境が以下の要件を満たしていることをご確認ください：

| 要件 | 対応バージョン | 備考 |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (`v20+` LTS 推奨) | JavaScript/TypeScript 実行環境およびパッケージマネージャー |
| **Rust** | 最新安定版 (`rustup default stable`) | Tauri ネイティブ Rust コアのコンパイルに必須 |
| **システムツール** | 各 OS 固有（下記参照） | C/C++ コンパイラーおよび WebView ランタイムライブラリ |

#### プラットフォーム別ビルド依存関係
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（「C++ によるデスクトップ開発」を選択）。
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)（Windows 10/11 に標準搭載）。

### 🔑 Telegram API 認証情報（任意）

TeleDrive にはローカル開発用の認証情報があらかじめ含まれています。ご自身の Telegram アプリケーション ID を使用したい場合：
1. [**my.telegram.org**](https://my.telegram.org) に電話番号でログインします。
2. **API development tools** に移動し、新規アプリを作成します（例: `TeleDrive-Dev`）。
3. `api_id` と `api_hash` をコピーします。
4. アプリ内の **設定 → API 設定** に入力するか、プロジェクト直下に `.env` ファイルを作成します：
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
