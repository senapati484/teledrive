## 💡 Por que o TeleDrive?

O Telegram oferece armazenamento em nuvem virtualmente ilimitado em canais privados, mas não possui hierarquia de pastas, catálogo virtual ou fluxo de trabalho de desktop. O **TeleDrive** resolve esse problema:

- **Zero Servidores Intermediários**: Todas as operações de arquivos e conexões MTProto ocorrem diretamente do seu computador local para os data centers do Telegram.
- **Drive Virtual**: Pastas aninhadas, busca instantânea, itens favoritos, arquivo e lixeira são indexados em um catálogo Schema v3 compactado em gzip, fixado no seu canal e armazenado localmente em cache no IndexedDB.
- **Privacidade do Lado do Cliente e Cofre Seguro**: As credenciais locais residem em um cofre Rust atômico / snapshot do Tauri Stronghold, com criptografia opcional de conhecimento zero `TDE1` PBKDF2-SHA256 + AES-256-GCM para os arquivos enviados.
- **Múltiplas Contas**: Alterne sem atrito entre vários números de telefone com isolamento completo de sessões e cofres locais.

## ✨ Recursos

- **Biometria por Hardware e Bloqueio do App (v0.1.5)**: Proteja seus arquivos com Touch ID, Windows Hello e Biometria Android, segurança com PIN dinâmico de 4 a 6 dígitos, escudo de privacidade em alternadores de janelas do SO e temporizadores de bloqueio automático por inatividade.
- **Verificador de Atualizações Integrado (v0.1.5)**: Verificação semântica automatizada de versões em segundo plano e sob demanda em relação aos lançamentos oficiais, com alertas de novidades e download direto de instaladores no SourceForge.
- **Nuvem Realmente Ilimitada**: Utiliza seu canal privado do Telegram como camada de armazenamento com 0 taxas recorrentes, detecção de duplicatas SHA-256 (`<= 2 GiB` clonagem de mensagens sem reenvio) e pontos de restauração.
- **Superação de Limites de Arquivo Único (`> 2/4 GB`)**: Divide automaticamente arquivos gigantes em segmentos ordenados determinísticos e os une de forma transparente em streaming durante o download.
- **Criptografia E2EE de Conhecimento Zero Opcional (`TDE1`)**: Criptografia cliente PBKDF2-SHA256 + AES-256-GCM em blocos de 512 KiB com suporte a busca de bloco aleatória.
- **Visualizador Universal Integrado e Miniaturas em Grade**:
  - Miniaturas reais em grade para imagens, vídeos reproduzíveis no navegador e PDFs (página 1).
  - Visualizadores nativos para PDFs (`pdf.js`), arquivos Office e OpenDocument (`.docx`, `.odt`, `.rtf`, `.epub`), planilhas com múltiplas abas (`.xlsx`, `.ods`, `.csv`, `.tsv`), apresentações (`.pptx`, `.odp`), arquivos compactados interativos (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), HTML isolado em sandbox, editor de código CodeMirror 6 (mais de 50 linguagens), texto UTF-16, fotos HEIC e streaming de mídia.
- **Multiplataforma Nativo e Ultraleve**: Binários otimizados para 5 plataformas (macOS, Windows, Linux, Android e iOS) construídos em Tauri v2 e Rust.
- **Backups Automáticos de Pastas e Sincronização Multidispositivo**: Manifestos locais `v2` com registro transacional para backups incrementais seguros contra falhas e sincronização delta entre dispositivos.
- **11 Idiomas Localizados**: Suporte nativo completo para Português (Brasil), Inglês, Espanhol, Alemão, Francês, Russo, Chinês (Simplificado e Tradicional), Hindi, Indonésio e Japonês.
- **Motor MTProto Pipelined**: Transmissão direta em blocos de 512 KiB com até 3 threads concorrentes `upload.GetFile` / `SaveBigFilePart` e controle adaptativo de limite `FloodWait`.

## ⚙️ Como Funciona

```
┌─────────────────────────────────────────────────────────────────┐
│                       Frontend React 19                         │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Estado Zustand   │             │ Motor Cliente GramJS│   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           MTProto Direto
       (Chamadas Bridge)                      (Seguro SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Núcleo Rust Tauri   │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │     (Canal Privado)    │
│  │ Cofre Stronghold  │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Conexão Direta**: Autentica-se diretamente com os servidores MTProto do Telegram pela porta segura TLS 443.
2. **Transferência Pipelined**: Fatie arquivos em partes de 512 KiB com pontos de recuperação, criptografia opcional `TDE1` AEAD e particionamento multissegmento para arquivos maiores que 2/4 GiB.
3. **Índice de Catálogo Fixado e Cache Local**: Mantém um índice JSON Schema v3 compactado em gzip fixado no seu canal através da fila de escrita única `IndexQueue`, hidratado na inicialização pelo IndexedDB (`teledrive_cache_v1`).

> 📘 **Aprofundamento Técnico:** Limites do sistema, diagramas de sequência, comandos IPC Tauri Rust e formato de criptografia disponíveis no [**Guia de Arquitetura e Engenharia Técnica (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Primeiros Passos

### 🛠️ Guia Rápido para Desenvolvedores e Colaboradores

O TeleDrive é 100% código aberto e pode ser configurado localmente em menos de 2 minutos. Possui credenciais embutidas de desenvolvimento, sem necessidade de registrar um aplicativo no Telegram.

#### 1. Clonar o Repositório
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Instalar Dependências
```bash
npm install
```
> ℹ️ *O hook `postinstall` aplica automaticamente patches de compatibilidade MTProto no GramJS (`scripts/patch-telegram.cjs`) para Tauri e navegadores.*

#### 3. Iniciar o Servidor de Desenvolvimento
```bash
# Iniciar o app desktop multiplataforma com hot-reload no Tauri v2:
npm run tauri dev

# Ou iniciar a pré-visualização web no navegador:
npm run dev
```

---

### 📋 Pré-requisitos

Certifique-se de que seu ambiente atenda aos seguintes requisitos mínimos antes de rodar localmente:

| Requisito | Versão Suportada | Notas |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (recomendado `v20+` LTS) | Runtime JavaScript/TypeScript e gerenciador de pacotes |
| **Rust** | Versão estável mais recente (`rustup default stable`) | Necessário para compilar o núcleo Rust do Tauri |
| **Toolchain do Sistema** | Específico por plataforma (veja abaixo) | Compilador C/C++ e bibliotecas de execução do webview |

#### Dependências Específicas de Compilação
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (selecione "Desenvolvimento para desktop com C++").
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (pré-instalado no Windows 10/11).

### 🔑 Credenciais da API do Telegram (Opcional)

O TeleDrive inclui credenciais integradas para desenvolvimento local. Se desejar usar suas próprias credenciais:
1. Faça login em [**my.telegram.org**](https://my.telegram.org) com seu número de telefone.
2. Acesse **API development tools** e crie uma nova aplicação (ex: `TeleDrive-Dev`).
3. Copie o `api_id` e o `api_hash`.
4. Insira-os no aplicativo em **Configurações → Configuração de API**, ou crie um arquivo `.env` na raiz:
   ```env
   VITE_TELEGRAM_API_ID=seu_api_id
   VITE_TELEGRAM_API_HASH=seu_api_hash
   ```
