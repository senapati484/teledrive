## 💡 Por que o TeleDrive?

O Telegram oferece armazenamento praticamente ilimitado em canais privados, mas não possui hierarquia de pastas, catálogo virtual ou fluxo de trabalho no desktop no estilo Google Drive. O **TeleDrive** resolve isso:

- **Zero Servidores Intermediários**: Todas as operações de arquivos e conexões MTProto acontecem diretamente da sua máquina local para os data centers do Telegram.
- **Drive Virtual**: Pastas aninhadas, pesquisa instantânea, favoritos, arquivo e lixeira são indexados em um catálogo fixado dentro do seu canal privado.
- **Cofre Local e E2EE (`TDE1`)**: Credenciais isoladas no cofre atômico Rust / Tauri Stronghold, com criptografia opcional no cliente PBKDF2-SHA256 + AES-256-GCM (`TDE1`) para arquivos.
- **Múltiplas Contas**: Alterne entre vários números de telefone com isolamento completo de sessão e cofre local.

## ✨ Recursos

- **Nuvem Ilimitada**: Utiliza seu canal privado do Telegram como camada de armazenamento com 0 taxas recorrentes.
- **Multiplataforma Nativo**: Aplicativo ultra-leve para 5 plataformas (macOS, Windows, Linux, Android e iOS) construído em Tauri v2 e Rust.
- **11 Idiomas Localizados**: Suporte nativo completo para Português (Brasil), Inglês, Espanhol, Alemão, Francês, Russo, Chinês (Simplificado e Tradicional), Hindi, Indonésio e Japonês.
- **Streaming Direto MTProto**: O motor GramJS transmite partes de 512 KB diretamente com até 4 threads simultâneas de upload.
- **Privacidade em Primeiro Lugar**: Sem rastreamento, telemetria oculta ou servidores intermediários. Seus arquivos ficam exclusivamente entre você e o Telegram.
- **Organização e Busca Instantânea**: Navegação por breadcrumbs, filtros por tipo de arquivo, visualização em grade ou lista e atalhos de teclado.

## ⚙️ Como Funciona

```
┌─────────────────────────────────────────────────────────────────┐
│                       Frontend em React 19                      │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Estado Zustand   │             │   Motor GramJS      │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           MTProto Direto
         (Chamadas Bridge)                    (SSL/TLS Seguro)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Núcleo Rust Tauri   │              │ API da Nuvem Telegram  │
│  ┌───────────────────┐  │              │    (Canal Privado)     │
│  │  Cofre Stronghold │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Conexão Direta**: Autentica diretamente com os servidores MTProto do Telegram pela porta TLS 443.
2. **Upload em Partes**: Divide arquivos grandes em fragmentos de 512 KB transmitidos concorrentemente.
3. **Catálogo de Pastas Fixado**: Mantém um índice de descritores JSON criptografado fixado no seu canal privado para sincronização entre dispositivos.

## 🚀 Como Começar

### 🛠️ Início Rápido para Desenvolvedores e Contribuidores

O TeleDrive é 100% código aberto e fácil de rodar localmente. Credenciais pré-configuradas para desenvolvimento já vêm embutidas, permitindo começar a contribuir em menos de 2 minutos sem precisar criar um app no Telegram.

#### 1. Clonar o repositório
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Instalar dependências
```bash
npm install
```
> ℹ️ *O hook `postinstall` aplica automaticamente os patches de compatibilidade do GramJS MTProto (`scripts/patch-telegram.cjs`) necessários para o Tauri e navegadores.*

#### 3. Iniciar o servidor de desenvolvimento
```bash
# Iniciar o aplicativo desktop com hot-reloading do Tauri v2:
npm run tauri dev

# Ou abrir a pré-visualização web no navegador:
npm run dev
```

---

### 📋 Pré-requisitos do Sistema

- **Node.js**: `>= 18.0.0` (`v20+` LTS recomendado)
- **Rust**: Versão estável mais recente (`rustup default stable`)
- **Ferramentas de compilação**:
  - **macOS**: `xcode-select --install`
  - **Linux (Debian/Ubuntu)**: `sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf`
  - **Linux (Fedora/RHEL)**: `sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel`
  - **Windows**: Microsoft Visual Studio C++ Build Tools & WebView2

### 🔑 Credenciais da API do Telegram (Opcional)

O TeleDrive já vem com credenciais de desenvolvimento embutidas. Se desejar testar com seu próprio aplicativo Telegram:
1. Acesse [**my.telegram.org**](https://my.telegram.org) com seu telefone.
2. Abra **API development tools** e crie uma aplicação (ex: `TeleDrive-Dev`).
3. Copie o `api_id` e `api_hash`.
4. Insira no TeleDrive em **Configurações → Configuração da API** ou crie um arquivo `.env`:
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
