## 💡 為什麼選擇 TeleDrive？

Telegram 在私有頻道中提供了近乎無限的雲端儲存容量，但缺乏資料夾階層、虛擬目錄索引以及傳統桌面雲端硬碟的操作體驗。**TeleDrive** 完美填補了這一空白：

- **無中繼代理伺服器**：所有檔案上傳下載及 MTProto 協定通訊均由本地裝置直連 Telegram 官方資料中心。
- **虛擬雲端硬碟工作流程**：多階層資料夾、即時搜尋、星號標記、封存與垃圾桶均由置頂於頻道內的 gzip 壓縮 Schema v3 目錄索引統一管理，並由本地 IndexedDB 進行高速快取。
- **用戶端隱私與加密保險箱**：本地登入憑證儲存在原子的 Rust 鍵值保險箱 / Tauri Stronghold 快照中，上傳檔案支援可選的零知識 `TDE1` PBKDF2-SHA256 + AES-256-GCM 端對端加密。
- **多帳號無縫切換**：支援在多個電話號碼之間快速切換，工作階段與本地加密儲存完全隔離。

## ✨ 核心特性

- **硬體生物辨識與應用程式鎖 (v0.1.5)**：透過 Touch ID、Windows Hello 和 Android 生物辨識保護雲端硬碟，支援 4–6 位動態安全 PIN 碼、系統多工切換防窺隱私遮罩以及逾時自動鎖定計時器。
- **應用程式內線上更新檢查 (v0.1.5)**：基於官方發布的自動背景與即時語意版本檢查，具備應用程式內更新彈窗提醒與直達 SourceForge 安裝包下載能力。
- **真·無限制雲端儲存**：以私密 Telegram 頻道作為永久後端，無任何持續訂閱費用；具備 SHA-256 重複檔案秒傳識別（`<= 2 GiB` 零上傳秒級訊息複製）與斷點續傳檢查點機制。
- **突破單一檔案大小上限 (`> 2/4 GB`)**：自動將超大檔案分割為確定性順序分段，在下載時無縫串流拼接還原。
- **可選端到端零知識加密 (`TDE1`)**：基於用戶端 PBKDF2-SHA256 + 512 KiB 分塊 AES-256-GCM 高效能加密，支援隨機存取區塊 Seek。
- **萬能內建預覽器與網格縮圖**：
  - 圖片、瀏覽器可播放影片、PDF 檔案（首頁）的原生網格縮圖渲染。
  - 原生支援 PDF 預覽 (`pdf.js`)、微軟 Office 與 OpenDocument 文件 (`.docx`, `.odt`, `.rtf`, `.epub`)、多工作表試算表 (`.xlsx`, `.ods`, `.csv`, `.tsv`)、簡報投影片 (`.pptx`, `.odp`)、互動式壓縮檔 (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`)、沙箱隔離 HTML、CodeMirror 6 程式碼編輯（支援 50+ 種語言）、UTF-16 文字、HEIC 相片以及全格式媒體串流播放。
- **極簡原生跨平台**：基於 Tauri v2 與 Rust 構建，輕量高效，記憶體佔用極低（通常低於 250 MB）。
- **自動化資料夾備份與跨裝置同步**：帶有本機交易記錄的 `v2` 增量備份引擎與多端即時 Delta 差異輪詢機制。
- **原生支援 11 種國際化語言**：繁體中文、簡體中文、英語、西班牙語、德語、法語、葡萄牙語、俄語、印地語、印尼語與日語。
- **管線化 MTProto 引擎**：512 KiB 分塊直傳，支援多達 3 個並行 MTProto `upload.GetFile` / `SaveBigFilePart` 傳輸工作執行緒與自適應 `FloodWait` 限速流控。

## ⚙️ 架構原理

```
┌─────────────────────────────────────────────────────────────────┐
│                       React 19 前端展示層                       │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Zustand 全域狀態 │             │ GramJS 用戶端核心   │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           直連 MTProto
         (內部橋接呼叫)                        (安全 SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Tauri Rust 核心     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │      (私有專屬頻道)     │
│  │ Stronghold 保險箱 │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **直接通訊連線**：透過安全的 TLS 443 埠直連 Telegram 官方 MTProto 節點並完成鑑權。
2. **管線化分塊傳輸**：大檔案自動切分成 512 KiB 區塊並行傳輸，帶斷點續傳檢查點，超 2/4 GiB 檔案自動多段分片。
3. **置頂目錄索引與本機快取**：透過單一寫入佇列 `IndexQueue` 維護置頂於頻道的 gzip 壓縮 Schema v3 目錄樹，並在啟動時從本機 IndexedDB (`teledrive_cache_v1`) 秒級復原。

> 📘 **深度技術指南：** 查閱系統邊界、循序圖、Tauri Rust IPC 命令、加密格式與底層模組拆解，請參閱 [**技術架構設計與工程指南 (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md)。

## 🚀 快速上手

### 🛠️ 開發者與貢獻者極速起步

TeleDrive 100% 原始碼開源，且內建開發環境免設定憑證，無需單獨前往 Telegram 註冊開發者 App，2 分鐘內即可在本機啟動運行。

#### 1. 複製程式碼倉庫
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. 安裝專案依賴套件
```bash
npm install
```
> ℹ️ *`postinstall` 鉤子會自動對 GramJS 注入 Tauri 和瀏覽器環境相容修補程式 (`scripts/patch-telegram.cjs`)。*

#### 3. 啟動開發伺服器
```bash
# 啟動跨平台桌面應用程式（支援 Tauri v2 熱重載）：
npm run tauri dev

# 或在瀏覽器中預覽 Web 用戶端：
npm run dev
```

### 📋 環境需求

在本機建置或運行之前，請確認您的系統滿足以下最低設定要求：

| 設定項目 | 最低版本要求 | 說明 |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (建議 `v20+` LTS) | JavaScript/TypeScript 執行階段及套件管理工具 |
| **Rust** | 最新穩定版 (`rustup default stable`) | 編譯 Tauri 本地 Rust 核心必需 |
| **系統編譯工具鏈** | 依據作業系統而定 (見下方) | C/C++ 編譯器及 WebView 底層支援庫 |

#### 各平台編譯相依套件
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（勾選「使用 C++ 的桌面開發」）。
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)（Windows 10/11 通常已內建）。

### 🔑 Telegram API 憑證設定（選用）

TeleDrive 已內建本地開發憑據。如需使用您個人的 Telegram 應用程式：
1. 使用手機號碼登入 [**my.telegram.org**](https://my.telegram.org)。
2. 進入 **API development tools** 建立應用程式（例如 `TeleDrive-Dev`）。
3. 複製產生的 `api_id` 與 `api_hash`。
4. 在軟體內的 **設定 → API 設定** 中填入，或在專案根目錄新增 `.env` 檔案：
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
