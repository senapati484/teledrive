## 💡 ¿Por qué TeleDrive?

Telegram ofrece almacenamiento en la nube virtualmente ilimitado en canales privados, pero carece de jerarquía de carpetas, catálogo virtual y flujo de trabajo de unidad de escritorio. **TeleDrive** cubre esa necesidad:

- **Sin Servidores Intermedios**: Todas las transferencias de archivos y conexiones MTProto se realizan directamente desde tu máquina local a los centros de datos de Telegram.
- **Unidad Virtual**: Carpetas anidadas, búsqueda instantánea, archivos destacados, archivo y papelera se indexan en un catálogo Schema v3 comprimido con gzip, anclado en tu canal y guardado en caché local en IndexedDB.
- **Privacidad del Lado del Cliente y Bóveda Segura**: Las credenciales locales se almacenan en una bóveda atómica de clave-valor en Rust / instantánea de Tauri Stronghold, con cifrado opcional de conocimiento cero `TDE1` PBKDF2-SHA256 + AES-256-GCM para archivos subidos.
- **Múltiples Cuentas**: Cambio fluido entre varios números de teléfono con aislamiento completo de sesiones y bóvedas locales.

## ✨ Características

- **Biometría por Hardware y Bloqueo de App (v0.1.5)**: Protege tu unidad con Touch ID, Windows Hello y biometría de Android, PIN dinámico personalizable de 4 a 6 dígitos, escudo de privacidad en conmutadores de ventanas y temporizadores de bloqueo automático por inactividad.
- **Comprobador de Actualizaciones en la App (v0.1.5)**: Verificación semántica automatizada en segundo plano y a petición con alertas de versión integradas y acceso directo a los instaladores de SourceForge.
- **Nube Realmente Ilimitada**: Utiliza tu canal privado de Telegram como almacenamiento con 0 pagos recurrentes, detección de duplicados SHA-256 (`<= 2 GiB` clonación de mensajes sin subida) y puntos de control reanudables.
- **Superación de Límites de Archivo Individual (`> 2/4 GB`)**: Divide automáticamente archivos grandes en segmentos ordenados deterministas y los une de forma continua en streaming al descargarlos.
- **Cifrado E2EE Opcional de Conocimiento Cero (`TDE1`)**: Cifrado AES-256-GCM en fragmentos de 512 KiB derivado de PBKDF2-SHA256 del lado del cliente con búsqueda de bloques de acceso aleatorio.
- **Visor Universal Integrado y Miniaturas en Cuadrícula**:
  - Miniaturas reales en cuadrícula para imágenes, vídeos reproducibles en el navegador y PDFs (página 1).
  - Visores nativos para PDF (`pdf.js`), archivos Office y OpenDocument (`.docx`, `.odt`, `.rtf`, `.epub`), hojas de cálculo multipestaña (`.xlsx`, `.ods`, `.csv`, `.tsv`), presentaciones (`.pptx`, `.odp`), archivos comprimidos interactivos (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), HTML aislado, editor de código CodeMirror 6 (más de 50 lenguajes), texto UTF-16, imágenes HEIC y streaming de medios.
- **Multiplataforma Nativo y Ultraligero**: Binarios optimizados para 5 plataformas (macOS, Windows, Linux, Android e iOS) construidos con Tauri v2 y Rust.
- **Copias de Seguridad de Carpetas y Sincronización Multidispositivo**: Manifiestos locales `v2` con registro por diario para copias de seguridad incrementales a prueba de caídas y sincronización delta de canales entre múltiples dispositivos.
- **11 Idiomas Localizados**: Soporte de interfaz nativo completo para Español, Inglés, Portugués, Francés, Alemán, Ruso, Chino (Simplificado y Tradicional), Hindi, Indonesio y Japonés.
- **Motor MTProto Pipelined**: Transmisión directa en bloques de 512 KiB con hasta 3 subprocesos concurrentes `upload.GetFile` / `SaveBigFilePart` y gestión adaptativa de límites de velocidad `FloodWait`.

## ⚙️ Cómo Funciona

```
┌─────────────────────────────────────────────────────────────────┐
│                       Frontend React 19                         │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Estado Zustand   │             │ Motor Cliente GramJS│   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           MTProto Directo
       (Llamadas Puente)                      (Seguro SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Núcleo Rust Tauri   │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │    (Canal Privado)     │
│  │ Bóveda Stronghold │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Conexión Directa**: Autenticación directa con los servidores MTProto de Telegram mediante el puerto seguro TLS 443.
2. **Transferencia de Medios Pipelined**: Divide los archivos en fragmentos de 512 KiB con puntos de control reanudables, cifrado opcional `TDE1` AEAD y partición multisegmento para archivos de más de 2/4 GiB.
3. **Índice de Catálogo Anclado y Caché Local**: Mantiene un índice JSON Schema v3 comprimido con gzip anclado a tu canal mediante una cola de escritura única `IndexQueue`, hidratado al iniciar desde IndexedDB (`teledrive_cache_v1`).

> 📘 **Análisis en Profundidad:** Límites del sistema, diagramas de secuencia, comandos IPC de Tauri Rust, formato de cifrado y módulos en la [**Guía Técnica de Arquitectura e Ingeniería (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Primeros Pasos

### 🛠️ Inicio Rápido para Desarrolladores y Colaboradores

TeleDrive es 100% código abierto y se configura localmente en menos de 2 minutos. Incluye credenciales de desarrollo integradas para que no necesites crear una aplicación de desarrollador en Telegram.

#### 1. Clonar el Repositorio
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Instalar Dependencias
```bash
npm install
```
> ℹ️ *El gancho `postinstall` aplica automáticamente los parches de compatibilidad MTProto para GramJS (`scripts/patch-telegram.cjs`) requeridos en Tauri y navegadores.*

#### 3. Iniciar el Servidor de Desarrollo
```bash
# Iniciar la aplicación de escritorio multiplataforma con hot-reloading de Tauri v2:
npm run tauri dev

# O iniciar la vista previa del cliente web en el navegador:
npm run dev
```

### 📋 Requisitos Previos

Asegúrate de que tu entorno de desarrollo cumpla con los siguientes requisitos mínimos:

| Requisito | Versión Soportada | Notas |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (recomendado `v20+` LTS) | Entorno JavaScript/TypeScript y gestor de paquetes |
| **Rust** | Última versión estable (`rustup default stable`) | Requerido para compilar el núcleo nativo de Tauri |
| **Toolchain del Sistema** | Específico por plataforma (ver abajo) | Compilador C/C++ y bibliotecas de ejecución webview |

#### Dependencias de Compilación Específicas por Plataforma
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (seleccionar «Desarrollo para el escritorio con C++»).
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (preinstalado en Windows 10/11).

### 🔑 Credenciales de Telegram API (Opcional)

TeleDrive incluye credenciales integradas para desarrollo local. Si deseas utilizar tus propios identificadores de Telegram:
1. Inicia sesión en [**my.telegram.org**](https://my.telegram.org) con tu número de teléfono.
2. Ve a **API development tools** y crea una aplicación (por ejemplo, `TeleDrive-Dev`).
3. Copia `api_id` y `api_hash`.
4. Introdúcelos en TeleDrive en **Ajustes → Configuración de API**, o crea un archivo `.env` en la raíz del proyecto:
   ```env
   VITE_TELEGRAM_API_ID=tu_api_id
   VITE_TELEGRAM_API_HASH=tu_api_hash
   ```
