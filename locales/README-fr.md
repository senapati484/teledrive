## 💡 Pourquoi TeleDrive ?

Telegram propose un stockage cloud virtuellement illimité dans ses canaux privés, mais sans hiérarchie de dossiers, catalogue virtuel ni interface de bureau de type drive. **TeleDrive** comble cet écart :

- **Aucun Serveur Relais** : Toutes les opérations de fichiers et connexions MTProto s'effectuent directement depuis votre appareil local vers les centres de données de Telegram.
- **Drive Virtuel** : Dossiers imbriqués, recherche instantanée, favoris, archive et corbeille sont indexés dans un catalogue Schema v3 compressé en gzip, épinglé dans votre canal et mis en cache localement dans IndexedDB.
- **Confidentialité Côté Client et Coffre-fort Local** : Vos identifiants résident dans un coffre-fort atomique clé-valeur Rust / instantané Tauri Stronghold, avec chiffrement optionnel à divulgation nulle de connaissance `TDE1` PBKDF2-SHA256 + AES-256-GCM pour les fichiers transférés.
- **Multi-Comptes** : Basculez en toute fluidité entre plusieurs numéros de téléphone avec une isolation complète des sessions et des coffres locaux.

## ✨ Fonctionnalités

- **Biométrie matérielle & Verrouillage de l'application (v0.1.5)** : Sécurisez votre drive avec Touch ID, Windows Hello et la biométrie Android, un code PIN dynamique personnalisable de 4 à 6 chiffres, un bouclier de confidentialité lors du changement de fenêtre et un verrouillage automatique par minuterie.
- **Vérificateur de mises à jour intégré (v0.1.5)** : Détection sémantique automatique des versions en arrière-plan et à la demande avec alertes intégrées et accès direct aux installateurs SourceForge.
- **Stockage Cloud Réellement Illimité** : Utilise votre canal privé Telegram sans frais récurrents, avec détection des doublons SHA-256 (`<= 2 Gio` clonage de message sans renvoi) et points de reprise.
- **Dépassement de la Limite de Fichier Unique (`> 2/4 Go`)** : Découpe automatiquement les très gros fichiers en segments déterministes ordonnés et les réassemble de manière transparente en flux continu lors du téléchargement.
- **Chiffrement E2EE optionnel à divulgation nulle (`TDE1`)** : Chiffrement client PBKDF2-SHA256 + AES-256-GCM par blocs de 512 Kio avec positionnement aléatoire.
- **Visionneuse Universelle Intégrée & Miniatures en Grille** :
  - Vraies miniatures en grille pour images, vidéos lisibles dans le navigateur et fichiers PDF (page 1).
  - Visionneuses natives pour PDF (`pdf.js`), fichiers bureautiques Office et OpenDocument (`.docx`, `.odt`, `.rtf`, `.epub`), classeurs multi-feuilles (`.xlsx`, `.ods`, `.csv`, `.tsv`), présentations (`.pptx`, `.odp`), archives interactives (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), HTML isolé, éditeur de code CodeMirror 6 (plus de 50 langages), texte UTF-16, images HEIC et streaming multimédia.
- **Léger et multiplateforme natif** : Développé avec Tauri v2 et Rust pour 5 plateformes (macOS, Windows, Linux, Android et iOS) avec une réactivité instantanée et une empreinte mémoire minimale (< 250 Mo).
- **Sauvegardes de dossiers automatisées & Synchronisation multi-appareils** : Manifestes locaux journalisés `v2` pour des sauvegardes incrémentielles résistantes aux plantages et synchronisation delta entre plusieurs appareils.
- **11 Langues Localisées** : Prise en charge native du français, anglais, espagnol, allemand, portugais, russe, chinois (simplifié et traditionnel), hindi, indonésien et japonais.
- **Moteur MTProto Pipelined** : Streaming direct par blocs de 512 Kio avec jusqu'à 3 workers MTProto concurrents `upload.GetFile` / `SaveBigFilePart` et gestion adaptative du débit `FloodWait`.

## ⚙️ Fonctionnement

```
┌─────────────────────────────────────────────────────────────────┐
│                       Frontend React 19                         │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    État Zustand     │             │ Moteur Client GramJS│   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           MTProto Direct
       (Appels Passerelle)                    (Sécurisé SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Cœur Rust Tauri     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │     (Canal Privé)      │
│  │ Coffre Stronghold │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Connexion Directe** : Authentification directe auprès des serveurs MTProto de Telegram via le port sécurisé TLS 443.
2. **Transfert Pipelined** : Découpage des fichiers en blocs de 512 Kio avec points de reprise, chiffrement AEAD `TDE1` optionnel et fractionnement multi-segments pour les fichiers dépassant 2/4 Gio.
3. **Index de Catalogue Épinglé & Cache Local** : Maintien d'un index JSON Schema v3 compressé en gzip épinglé sur votre canal via une file d'écriture unique `IndexQueue`, hydraté au démarrage depuis IndexedDB (`teledrive_cache_v1`).

> 📘 **Analyse Approfondie :** Limites du système, diagrammes de séquence, commandes IPC Tauri Rust, structure de chiffrement et modules détaillés dans le [**Guide Technique d'Architecture & d'Ingénierie (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Prise en Main

### 🛠️ Démarrage Rapide pour Développeurs & Contributeurs

TeleDrive est 100 % open-source et se configure localement en moins de 2 minutes. Des identifiants de développement intégrés vous évitent de devoir créer une application développeur sur Telegram.

#### 1. Cloner le Dépôt
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Installer les Dépendances
```bash
npm install
```
> ℹ️ *Le hook `postinstall` applique automatiquement les correctifs de compatibilité MTProto pour GramJS (`scripts/patch-telegram.cjs`) indispensables pour Tauri et les navigateurs.*

#### 3. Lancer le Serveur de Développement
```bash
# Lancer l'application de bureau multiplateforme avec le rechargement à chaud Tauri v2 :
npm run tauri dev

# Ou lancer l'aperçu web dans le navigateur :
npm run dev
```

---

### 📋 Prérequis

Assurez-vous que votre environnement respecte les exigences minimales suivantes :

| Prérequis | Version prise en charge | Remarques |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (recommandé `v20+` LTS) | Runtime JavaScript/TypeScript et gestionnaire de paquets |
| **Rust** | Dernière version stable (`rustup default stable`) | Requis pour compiler le cœur natif Tauri en Rust |
| **Toolchain Système** | Spécifique à la plateforme (voir ci-dessous) | Compilateur C/C++ et bibliothèques runtime webview |

#### Dépendances de Compilation par Plateforme
- **macOS** :
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)** :
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)** :
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows** :
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (sélectionner « Développement Desktop en C++ »).
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (préinstallé sur Windows 10/11).

### 🔑 Identifiants Telegram API (Optionnel)

TeleDrive comprend des identifiants intégrés pour le développement local. Si vous préférez utiliser vos propres identifiants API Telegram :
1. Connectez-vous sur [**my.telegram.org**](https://my.telegram.org) avec votre numéro de téléphone.
2. Allez dans **API development tools** et créez une application (par ex. `TeleDrive-Dev`).
3. Copiez votre `api_id` et votre `api_hash`.
4. Renseignez-les dans TeleDrive sous **Paramètres → Configuration de l'API**, ou créez un fichier `.env` à la racine :
   ```env
   VITE_TELEGRAM_API_ID=votre_api_id
   VITE_TELEGRAM_API_HASH=votre_api_hash
   ```
