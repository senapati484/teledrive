## 💡 Mengapa TeleDrive?

Telegram menyediakan penyimpanan cloud yang praktis tanpa batas di saluran privat, namun tidak memiliki hierarki folder, katalog virtual, dan alur kerja drive desktop. **TeleDrive** menjembatani kebutuhan tersebut:

- **Tanpa Server Perantara**: Semua operasi berkas dan koneksi MTProto berlangsung langsung dari komputer lokal Anda ke pusat data Telegram.
- **Drive Virtual**: Folder bertingkat, pencarian instan, file berbintang, arsip, dan tempat sampah diindeks dalam katalog Schema v3 terkompresi gzip yang disematkan di saluran Anda serta disimpan di IndexedDB lokal.
- **Privasi Sisi Klien & Brankas Aman**: Kredensial lokal tersimpan dalam brankas Rust atomik / snapshot Tauri Stronghold, dengan enkripsi zero-knowledge opsional `TDE1` PBKDF2-SHA256 + AES-256-GCM untuk file yang diunggah.
- **Multi-Akun**: Beralih antar-nomor telepon secara mulus dengan isolasi sesi dan brankas lokal penuh.

## ✨ Fitur Utama

- **Biometrik Perangkat Keras & Kunci Aplikasi (v0.1.5)**: Lindungi drive Anda dengan Touch ID, Windows Hello, dan Biometrik Android, keamanan PIN dinamis 4–6 digit yang dapat disesuaikan, pelindung privasi jendela latar belakang di app switcher OS, serta pengatur waktu kunci otomatis saat tidak aktif.
- **Pemeriksa Pembaruan Langsung di Dalam Aplikasi (v0.1.5)**: Pemeriksaan versi semantik otomatis di latar belakang maupun sesuai permintaan terhadap rilis resmi dengan peringatan rilis terintegrasi dan akses installer SourceForge langsung.
- **Penyimpanan Cloud Tanpa Batas**: Menggunakan saluran privat Telegram Anda sebagai media penyimpanan tanpa biaya berulang, deteksi duplikasi SHA-256 (`<= 2 GiB` kloning pesan tanpa unggah ulang), serta titik pemulihan unggahan.
- **Lewati Batas File Tunggal (`> 2/4 GB`)**: Memecah berkas berukuran besar secara deterministik menjadi segmen-segmen terurut dan menggabungkannya kembali secara mulus saat diunduh.
- **Enkripsi E2EE Zero-Knowledge Opsional (`TDE1`)**: Enkripsi sisi klien PBKDF2-SHA256 + 512 KiB chunked AES-256-GCM dengan kemampuan random-access block seeking.
- **Penampil Berkas Universal & Miniatur Kisi (Grid Thumbnails)**:
  - Miniatur kisi nyata untuk gambar, video yang didukung peramban, dan dokumen PDF (halaman 1).
  - Penampil berkas bawaan untuk PDF (`pdf.js`), dokumen Office & OpenDocument (`.docx`, `.odt`, `.rtf`, `.epub`), lembar kerja multilembar (`.xlsx`, `.ods`, `.csv`, `.tsv`), presentasi (`.pptx`, `.odp`), arsip interaktif (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), HTML terisolasi, editor kode CodeMirror 6 (50+ bahasa), teks UTF-16, gambar HEIC, dan streaming media.
- **Ringan & Multiplatform Asli**: Dibangun di atas Tauri v2 dan Rust untuk 5 platform (macOS, Windows, Linux, Android, dan iOS) dengan jejak memori yang sangat rendah (< 250 MB).
- **Pencadangan Folder Otomatis & Sinkronisasi Lintas Perangkat**: Manifes lokal `v2` berjurnal untuk pencadangan inkremental yang tahan crash dan sinkronisasi delta saluran lintas perangkat.
- **11 Bahasa Terlokalisasi**: Dukungan antarmuka native untuk Bahasa Indonesia, Inggris, Spanyol, Jerman, Prancis, Portugis, Rusia, Tionghoa (Sederhana & Tradisional), Hindi, dan Jepang.
- **Engine MTProto Pipelined**: Transmisi langsung pecahan 512 KiB dengan dukungan hingga 3 worker bersamaan `upload.GetFile` / `SaveBigFilePart` dan penanganan adaptif laju `FloodWait`.

## ⚙️ Cara Kerja

```
┌─────────────────────────────────────────────────────────────────┐
│                       Frontend React 19                         │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Status Zustand   │             │ Engine Klien GramJS │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           MTProto Langsung
       (Panggilan Bridge)                     (SSL/TLS Aman)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Tauri Rust Core     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │    (Saluran Privat)    │
│  │ Brankas Stronghold│  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Koneksi Langsung**: Melakukan autentikasi langsung ke server MTProto Telegram melalui port aman TLS 443.
2. **Transfer Media Pipelined**: Memotong file menjadi potongan 512 KiB dengan titik pemulihan, enkripsi AEAD `TDE1` opsional, dan segmentasi ganda untuk berkas melebihi 2/4 GiB.
3. **Indeks Katalog Tersemat & Cache Lokal**: Mengelola indeks JSON Schema v3 terkompresi gzip yang disematkan di saluran Anda melalui antrean penulisan tunggal `IndexQueue`, yang dimuat saat startup dari IndexedDB (`teledrive_cache_v1`).

> 📘 **Pelajari Lebih Lanjut:** Batasan sistem, diagram urutan, perintah IPC Tauri Rust, tata letak enkripsi, dan referensi modul tersedia di [**Panduan Arsitektur & Rekayasa Teknis (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Memulai

### 🛠️ Panduan Cepat untuk Kontributor & Pengembang

TeleDrive 100% open-source dan mudah disiapkan secara lokal dalam waktu kurang dari 2 menit. Sudah dilengkapi kredensial pengembangan bawaan tanpa perlu mendaftar aplikasi pengembang Telegram baru.

#### 1. Klon Repositori
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Pasang Dependensi
```bash
npm install
```
> ℹ️ *Skrip `postinstall` secara otomatis menerapkan patch kompatibilitas MTProto GramJS (`scripts/patch-telegram.cjs`) yang dibutuhkan untuk Tauri dan browser.*

#### 3. Jalankan Server Pengembangan
```bash
# Jalankan aplikasi desktop lintas platform dengan hot-reload Tauri v2:
npm run tauri dev

# Atau jalankan pratinjau klien web di peramban:
npm run dev
```

### 🔑 Kredensial API Telegram (Opsional)

TeleDrive menyertakan kredensial bawaan untuk pengembangan lokal. Jika Anda ingin menggunakan kredensial aplikasi Telegram pribadi Anda:
1. Masuk ke [**my.telegram.org**](https://my.telegram.org) dengan nomor telepon Anda.
2. Buka **API development tools** dan buat aplikasi baru (misalnya `TeleDrive-Dev`).
3. Salin `api_id` dan `api_hash`.
4. Masukkan di dalam aplikasi melalui **Pengaturan → Konfigurasi API**, atau buat file `.env` di folder utama:
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
