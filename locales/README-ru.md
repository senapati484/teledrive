## 💡 Почему TeleDrive?

Telegram предоставляет практически неограниченное облачное пространство в личных каналах, но не имеет иерархии папок, виртуального каталога и привычного интерфейса десктопного диска. **TeleDrive** решает эту проблему:

- **Без Промежуточных Серверов**: Все операции с файлами и подключения по протоколу MTProto происходят напрямую с вашего устройства на серверы Telegram.
- **Виртуальный Диск**: Вложенные каталоги, мгновенный поиск, избранное, архив и корзина индексируются в сжатом gzip каталоге Schema v3, закрепленном в вашем канале и кэшируемом локально в IndexedDB.
- **Локальная Конфиденциальность и Безопасное Хранилище**: Учетные данные хранятся в атомарном Rust key-value хранилище / снимке Tauri Stronghold, с возможностью включения сквозного шифрования с нулевым разглашением `TDE1` PBKDF2-SHA256 + AES-256-GCM.
- **Мульти-Аккаунт**: Удобное переключение между несколькими номерами телефонов с полной изоляцией сессий и локальных хранилищ.

## ✨ Возможности

- **Аппаратная биометрия и блокировка приложения (v0.1.5)**: Защита вашего диска с помощью Touch ID, Windows Hello и биометрии Android, настраиваемый 4–6-значный динамический PIN-код, защита конфиденциальности в окне переключения приложений ОС и таймеры автоблокировки при бездействии.
- **Встроенная проверка обновлений (v0.1.5)**: Автоматическая фоновая и ручная проверка версий относительно официальных релизов с уведомлениями о новых версиях и прямым доступом к установщикам SourceForge.
- **Действительно безлимитное облако**: Ваш личный канал Telegram используется как хранилище без абонентской платы, с дедупликацией файлов SHA-256 (`<= 2 ГиБ` мгновенное клонирование сообщений без повторной загрузки) и возможностью докачки.
- **Преодоление лимита размера файла (`> 2/4 ГБ`)**: Автоматическое детерминированное сегментирование больших файлов и прозрачное бесшовное объединение в потоке при скачивании.
- **Опциональное сквозное E2EE-шифрование с нулевым разглашением (`TDE1`)**: Клиентское шифрование PBKDF2-SHA256 + 512 КиБ блочное AES-256-GCM с поддержкой произвольного доступа к блокам.
- **Универсальный встроенный просмотрщик и сетка миниатюр**:
  - Настоящие миниатюры для изображений, видеофайлов и документов PDF (страница 1).
  - Встроенный просмотр PDF (`pdf.js`), документов Office и OpenDocument (`.docx`, `.odt`, `.rtf`, `.epub`), электронных таблиц (`.xlsx`, `.ods`, `.csv`, `.tsv`), презентаций (`.pptx`, `.odp`), интерактивных архивов (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), изолированного HTML, редактор кода CodeMirror 6 (50+ языков), текст UTF-16, фото HEIC и медиастриминг.
- **Нативная кроссплатформенность**: Легковесное приложение для 5 платформ (macOS, Windows, Linux, Android и iOS) на базе Tauri v2 и Rust с минимальным потреблением ресурсов (< 250 МБ).
- **Автоматическое резервное копирование папок и синхронизация**: Журналируемые локальные манифесты `v2` для инкрементного копирования с защитой от сбоев и дельта-синхронизация между устройствами.
- **11 локализованных языков**: Полная нативная поддержка русского, английского, испанского, немецкого, французского, португальского, китайского (упрощенного и традиционного), хинди, индонезийского и японского языков.
- **Конвейерный движок MTProto**: Прямая потоковая передача блоками по 512 КиБ с поддержкой до 3 параллельных воркеров `upload.GetFile` / `SaveBigFilePart` и адаптивной обработкой лимитов `FloodWait`.

## ⚙️ Архитектура и принципы работы

```
┌─────────────────────────────────────────────────────────────────┐
│                       Фронтенд React 19                         │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Состояние Zustand│             │ Клиентский движок   │   │
│   │                     │             │ GramJS              │   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           Прямой MTProto
       (Мостовые вызовы)                      (Защищенный SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│    Ядро Tauri на Rust   │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │    (Приватный канал)   │
│  │Сейф Stronghold    │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Прямое соединение**: Прямая авторизация на серверах MTProto Telegram через защищенный порт TLS 443.
2. **Конвейерная передача данных**: Разделение файлов на фрагменты по 512 КиБ с точками возобновления, опциональным AEAD-шифрованием `TDE1` и сегментированием файлов более 2/4 ГиБ.
3. **Закрепленный индекс каталога и локальный кэш**: Поддержание сжатого gzip индекса JSON Schema v3 в вашем канале с помощью единой очереди записи `IndexQueue`, загружаемого при старте из IndexedDB (`teledrive_cache_v1`).

> 📘 **Глубокий технический анализ:** Границы системы, диаграммы последовательностей, IPC-команды Tauri Rust, формат шифрования и описание модулей в [**Техническом руководстве по архитектуре (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Начало работы

### 🛠️ Быстрый старт для разработчиков

TeleDrive на 100% бесплатен и имеет открытый исходный код. Развертывание локально занимает менее 2 минут благодаря встроенным учетным данным разработки, не требующим создания приложения на Telegram API.

#### 1. Клонировать репозиторий
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Установить зависимости
```bash
npm install
```
> ℹ️ *Скрипт `postinstall` автоматически применяет патчи совместимости GramJS MTProto (`scripts/patch-telegram.cjs`), необходимые для работы в Tauri и веб-браузерах.*

#### 3. Запустить сервер разработки
```bash
# Запуск кроссплатформенного приложения с горячей перезагрузкой Tauri v2:
npm run tauri dev

# Или запуск веб-версии в браузере:
npm run dev
```

### 🔑 Учетные данные Telegram API (Необязательно)

TeleDrive включает предустановленные учетные данные для локальной разработки. Если вы хотите использовать собственное приложение Telegram:
1. Авторизуйтесь на [**my.telegram.org**](https://my.telegram.org) по номеру телефона.
2. Перейдите в раздел **API development tools** и создайте приложение (например, `TeleDrive-Dev`).
3. Скопируйте `api_id` и `api_hash`.
4. Введите их в приложении в разделе **Настройки → Конфигурация API** или создайте файл `.env` в корневой папке:
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```

| `Backspace` / `Del` | Переместить выбранный элемент в Корзину |
| `Esc` | Снять выделение / убрать фокус с поиска |
| `?` | Показать справку по горячим клавишам |
