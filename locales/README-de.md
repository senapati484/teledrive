## 💡 Warum TeleDrive?

Telegram bietet in privaten Kanälen praktisch unbegrenzten Cloud-Speicher, jedoch ohne Ordnerhierarchie, virtuellen Katalog oder klassischen Desktop-Drive-Workflow. **TeleDrive** schließt diese Lücke:

- **Keine Zwischenserver**: Sämtliche Dateiübertragungen und MTProto-Verbindungen laufen direkt von Ihrem lokalen Computer zu den Telegram-Rechenzentren.
- **Virtuelles Laufwerk**: Verschachtelte Ordner, Sofortsuche, Favoriten, Archiv und Papierkorb werden in einem mit gzip komprimierten Schema v3-Katalog in Ihrem Kanal verwaltet und lokal in IndexedDB zwischengespeichert.
- **Client-Datenschutz & Lokaler Tresor**: Zugangsdaten liegen im atomaren Rust-Schlüssel-Wert-Tresor / Tauri Stronghold-Snapshot; optionales clientseitiges Zero-Knowledge `TDE1` PBKDF2-SHA256 + AES-256-GCM verschlüsselt hochgeladene Dateien Ende-zu-Ende.
- **Multi-Account**: Nahtloses Umschalten zwischen mehreren Telefonnummern mit vollständiger Sitzungs- und Tresorisolierung.

## ✨ Features

- **Hardware-Biometrie & App-Sperre (v0.1.5)**: Schützen Sie Ihr Laufwerk mit Touch ID, Windows Hello und Android-Biometrie, konfigurierbarer 4–6-stelliger dynamischer PIN, Privatsphäre-Sichtschutz im Betriebssystem-App-Umschalter und automatischer Inaktivitätssperre.
- **Live-Update-Prüfung in der App (v0.1.5)**: Automatische Hintergrund- und manuelle Versionsprüfung gegen offizielle Releases mit Update-Benachrichtigungen und direktem Zugriff auf SourceForge-Installationsdateien.
- **Echter unbegrenzter Speicher**: Nutzt Ihren privaten Telegram-Kanal als Cloud-Backend ohne wiederkehrende Gebühren, SHA-256-Duplikaterkennung (`<= 2 GiB` Zero-Upload Nachrichtenklonung) und fortsetzbare Upload-Checkpoints.
- **Überwindung von Einzeldatei-Limits (`> 2/4 GB`)**: Teilt übergroße Dateien automatisch in deterministische Segmente auf und fügt sie beim Herunterladen nahtlos als Stream wieder zusammen.
- **Optionales Zero-Knowledge E2EE (`TDE1`)**: Clientseitige PBKDF2-SHA256 + 512 KiB blockbasierte AES-256-GCM-Verschlüsselung mit direktem Random-Access-Blockzugriff.
- **Universelle integrierte Dateivorschau & Raster-Thumbnails**:
  - Echte Raster-Miniaturansichten für Bilder, im Browser abspielbare Videos und PDFs (Seite 1).
  - Native Vorschau für PDFs (`pdf.js`), Office- und OpenDocument-Dateien (`.docx`, `.odt`, `.rtf`, `.epub`), Tabellenkalkulationen mit mehreren Arbeitsblättern (`.xlsx`, `.ods`, `.csv`, `.tsv`), Präsentationen (`.pptx`, `.odp`), interaktive Archive (`.zip`, `.tar`, `.tar.gz`, `.tgz`, `.gz`, `.apk`, `.jar`), isoliertes HTML, CodeMirror 6 Code-Editor (über 50 Sprachen), UTF-16-Text, HEIC-Bilder und Medienstreaming.
- **Nativ und plattformübergreifend**: Schlanke Anwendung für 5 Plattformen (macOS, Windows, Linux, Android und iOS), entwickelt mit Tauri v2 und Rust.
- **Automatische Verzeichnis-Backups & geräteübergreifende Synchronisierung**: Journalbasierte `v2` lokale Manifeste für absturzsichere inkrementelle Verzeichnis-Backups und schreibgeschützte Multi-Geräte-Delta-Kanal-Synchronisierung.
- **11 lokalisierte Sprachen**: Vollständige Lokalisierung für Deutsch, Englisch, Spanisch, Französisch, Portugiesisch, Russisch, Chinesisch (vereinfacht & traditionell), Hindi, Indonesisch und Japanisch.
- **Pipelined MTProto-Engine**: Direktes 512-KiB-Block-Streaming mit bis zu 3 parallelen MTProto `upload.GetFile` / `SaveBigFilePart`-Workern und adaptiver `FloodWait`-Ratenbegrenzungsbehandlung.

## ⚙️ Funktionsweise

```
┌─────────────────────────────────────────────────────────────────┐
│                      React 19 Frontend                          │
│   ┌─────────────────────┐             ┌─────────────────────┐   │
│   │    Zustand State    │             │ GramJS Client Engine│   │
│   └──────────┬──────────┘             └──────────┬──────────┘   │
└──────────────┼───────────────────────────────────┼──────────────┘
               │                                   │
           Tauri IPC                           Direktes MTProto
        (Bridge-Aufrufe)                      (Sicheres SSL/TLS)
               │                                   │
┌──────────────▼──────────┐              ┌─────────▼──────────────┐
│     Tauri Rust Core     │              │   Telegram Cloud API   │
│  ┌───────────────────┐  │              │    (Privater Kanal)    │
│  │ Stronghold Vault  │  │              └────────────────────────┘
│  └───────────────────┘  │
└─────────────────────────┘
```

1. **Direktverbindung**: Authentifiziert sich über den sicheren TLS-Port 443 direkt bei den Telegram-MTProto-Servern.
2. **Pipelined-Medientransfer**: Zerlegt Dateien in 512-KiB-Segmente mit fortsetzbaren Prüfpunkten, optionaler `TDE1`-AEAD-Verschlüsselung und Multi-Segment-Aufteilung für Dateien über 2/4 GiB.
3. **Angehefteter Katalog & Lokaler Cache**: Hält einen gzip-komprimierten Schema v3 JSON-Index im Kanal synchron über eine Single-Writer `IndexQueue`, beim Start initialisiert aus IndexedDB (`teledrive_cache_v1`).

> 📘 **Architektur-Details:** Systemgrenzen, Sequenzdiagramme, Tauri Rust IPC-Befehle, Verschlüsselungsaufbau und Modulreferenzen finden Sie im ausführlichen [**Technischen Architektur- und Entwicklerleitfaden (`docs/ARCHITECTURE.md`)**](../docs/ARCHITECTURE.md).

## 🚀 Erste Schritte

### 🛠️ Schnellstart für Entwickler & Mitwirkende

TeleDrive ist 100 % Open Source und lokal in unter zwei Minuten eingerichtet. Dank vorkonfigurierter Entwickler-Zugangsdaten ist kein eigenes Telegram-Entwicklerkonto nötig.

#### 1. Repository klonen
```bash
git clone https://github.com/senapati484/teledrive.git
cd teledrive
```

#### 2. Abhängigkeiten installieren
```bash
npm install
```
> ℹ️ *Der `postinstall`-Hook wendet automatisch GramJS MTProto-Kompatibilitätspatches (`scripts/patch-telegram.cjs`) für Tauri- und Browser-Laufzeiten an.*

#### 3. Entwicklungsserver starten
```bash
# Plattformübergreifende Desktop-App mit Tauri v2 Hot-Reloading starten:
npm run tauri dev

# Oder Web-Client-Vorschau im Browser starten:
npm run dev
```

### 📋 Systemvoraussetzungen

Stellen Sie vor der lokalen Ausführung sicher, dass Ihre Entwicklungsumgebung folgende Mindestanforderungen erfüllt:

| Anforderung | Unterstützte Version | Anmerkungen |
|:---|:---|:---|
| **Node.js** | `>= 18.0.0` (`v20+` LTS empfohlen) | JavaScript/TypeScript-Laufzeitumgebung und Paketwerkzeuge |
| **Rust** | Aktuelle stabile Version (`rustup default stable`) | Erforderlich zur Kompilierung des nativen Tauri-Rust-Kerns |
| **System-Toolchain** | Plattformspezifisch (siehe unten) | C/C++-Compiler und WebView-Laufzeitbibliotheken |

#### Plattformspezifische Build-Abhängigkeiten
- **macOS**:
  ```bash
  xcode-select --install
  ```
- **Linux (Ubuntu / Debian)**:
  ```bash
  sudo apt update && sudo apt install -y build-essential libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf
  ```
- **Linux (Fedora / RHEL)**:
  ```bash
  sudo dnf install -y webkit2gtk4.1-devel openssl-devel libappindicator-gtk3-devel librsvg2-devel
  ```
- **Windows**:
  - [Visual Studio C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (Option „Desktopentwicklung mit C++“ auswählen).
  - [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (unter Windows 10/11 vorinstalliert).

### 🔑 Telegram API-Zugangsdaten (Optional)

TeleDrive enthält bereits eingebaute Zugangsdaten für die lokale Entwicklung. Wenn Sie Ihre eigenen Telegram-API-Daten verwenden möchten:
1. Melden Sie sich unter [**my.telegram.org**](https://my.telegram.org) mit Ihrer Telefonnummer an.
2. Erstellen Sie unter **API development tools** eine Anwendung (z. B. `TeleDrive-Dev`).
3. Kopieren Sie `api_id` und `api_hash`.
4. Tragen Sie diese in TeleDrive unter **Einstellungen → API-Konfiguration** ein oder erstellen Sie eine `.env`-Datei im Hauptverzeichnis:
   ```env
   VITE_TELEGRAM_API_ID=your_api_id
   VITE_TELEGRAM_API_HASH=your_api_hash
   ```
