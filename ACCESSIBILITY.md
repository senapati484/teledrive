# Accessibility Statement for TeleDrive

TeleDrive is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone and applying the relevant accessibility standards.

## Measures to Support Accessibility

TeleDrive takes the following measures to ensure accessibility across its desktop, web, and mobile clients:

- **Semantic HTML & ARIA Attributes:** Using native HTML interactive elements (`<button>`, `<input>`, `<dialog>`) and standard ARIA roles for assistive technology.
- **Keyboard Navigation:** All interactive elements and core workflows (uploading, browsing, navigating settings, previewing files) are reachable and operable via keyboard alone.
- **Contrast & Theme Support:** Curated dark and light themes optimized for readability and high contrast, respecting WCAG 2.1 AA color contrast ratios.
- **Screen Reader Compatibility:** Providing clear labels, text alternatives, and informative states for screen readers (NVDA, VoiceOver, JAWS, TalkBack).
- **Reduced Motion:** Honoring user preferences for reduced motion (`prefers-reduced-motion`) across modal animations and transitions.

## Conformance Status

The [Web Content Accessibility Guidelines (WCAG)](https://www.w3.org/WAI/standards-guidelines/wcag/) defines requirements for designers and developers to improve accessibility for people with disabilities. TeleDrive aims to conform to **WCAG 2.1 Level AA**.
